jni-jasl-counters (test)

Building the unit tests

The purpose of each target defined in the Makefile for this directory is listed below. The files are written to or removed from the following output directory:
  • Executable files - .bin
Note that some of the targets are also referenced by the Makefile in the parent directory during recursive cleans and builds.
  • none or test - compiles all the source files using gcc, placing the executable files in the directory noted above.

  • clean - removes the directory noted above that contains the executable files.

  • docs - generates an HTML version of each source file and the Makefile using source-highlight, placing the output files in $JASL_BASE/share/jasl/doc/source/jni-wrapper/jasl/counters/test. This file, test.html, is also generated, and includes links to all of the HTML files.
